# TripEvent ✈🎫

פלטפורמת תכנון חופשות סביב הופעות, ספורט ואירועי תרבות.

## על הפרויקט

TripEvent מאפשרת למשתמשים למצוא חופשות שכוללות אירוע (הופעה/ספורט), טיסה, ומלון — הכל במקום אחד, בלי כאב ראש.

## התחלה מהירה

```bash
npm install
npm run dev
```

פתח [http://localhost:3000](http://localhost:3000) בדפדפן.

## דפים

| נתיב | תיאור |
|------|--------|
| `/` | דף ראשי — שאלון חיפוש + דילים חמים |
| `/trip/[id]` | דף מסלול מפורט |
| `/search` | תוצאות חיפוש |
| `/about` | אודות |
| `/faq` | שאלות נפוצות |

## טכנולוגיה

- **Next.js 14** (App Router) + TypeScript
- **Tailwind CSS** עם RTL מלא
- **פונט Heebo** עברי
- דיפלוי ל-**Vercel**

## דיפלוי

```bash
npm run build
```

או התחבר ל-[Vercel](https://vercel.com) עם ה-repo לדיפלוי אוטומטי.
